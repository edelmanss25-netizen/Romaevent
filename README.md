# Workspace — планировщик агентства

React + Vite + Supabase. Серебристо-графитовая тема, логотип в боковой панели.

## Что умеет

- **Календарь** — месяц/неделя, все события агентства, сроки задач, фильтры по сотруднику и группе. Клик по дню — новое событие.
- **События** — отдельная страница каждого мероприятия:
  - тайминг: отрезки времени, у каждого название, структура (пункты списком) и ответственный;
  - задействованные сотрудники с ролью на событии;
  - оборудование с количеством и предупреждением о занятости;
  - задачи по событию (доска).
- **Задачи** — доска с drag&drop; группировка по статусу, сотруднику, группе, событию, сроку, приоритету.
- **Сотрудники** — карточки по отделам; на странице сотрудника его задачи и ближайшие события.
- **Оборудование** — карточки по категориям; на странице техники график занятости (месяц), предстоящие брони, история и ручные блокировки (ремонт, аренда).
- Добавление, редактирование, удаление, группы (свободный текст с подсказками) везде. Изменения синхронизируются между пользователями в реальном времени.

## Запуск

### 1. Supabase
1. Создайте проект на https://supabase.com.
2. SQL Editor → вставьте содержимое `supabase/schema.sql` → Run.
3. Authentication → Providers → Email. Создайте пользователей в Authentication → Users (или разрешите регистрацию на время, а потом отключите: Authentication → Sign In / Providers → «Allow new users to sign up»).
   Доступ к данным есть у любого вошедшего пользователя, поэтому для закрытого агентства регистрацию лучше отключить.
4. Project Settings → API: скопируйте `Project URL` и `anon public` key.

### 2. Локально
```bash
cp .env.example .env     # вставьте URL и ключ
npm install
npm run dev
```

### 3. Vercel
1. Загрузите папку в GitHub-репозиторий и импортируйте его в Vercel (или `npx vercel`).
2. Framework: Vite (определится автоматически, настройки лежат в `vercel.json`).
3. Settings → Environment Variables: добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. Deploy. Переходы по прямым ссылкам (`/events/...`) работают благодаря rewrite в `vercel.json`.
5. Supabase → Authentication → URL Configuration: добавьте адрес сайта в Site URL (нужно для писем подтверждения).

## Структура

```
supabase/schema.sql      таблицы, RLS, realtime
src/data.jsx             загрузка данных + insert/update/remove
src/pages/*              страницы
src/components/*         формы, сетка календаря, доска задач
src/styles.css           тема (цвета в :root)
```

Цвета меняются в `:root` в `src/styles.css`.
